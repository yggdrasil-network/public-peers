# Brazil Peers

Add connection strings from the below list to the `Peers: []` section of your
Yggdrasil configuration file to peer with these nodes.

### Paraná

* Maringá, consumer grade connection, operated by [huzuni](https://github.com/huzunikkj), IPv6-only, 300 Mb/s
  * `tls://thinkmedia.freeddns.org:9002`

### São Paulo

* Jundiaí, consumer grade connection, operated by [UnderEu](https://mas.to/@UnderEu), IPv6-only
  * `tcp://Yggdrasil.UnderEu.Net:37001`
  * `tls://Yggdrasil.UnderEu.Net:37002`
  * `quic://Yggdrasil.UnderEu.Net:37003`
  * `ws://Yggdrasil.UnderEu.Net:37004`
